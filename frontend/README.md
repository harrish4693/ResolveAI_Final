# ResolveAI Frontend

Modern, high-performance web interface for the ResolveAI customer support platform, powered by Vite, TanStack Router, Tailwind CSS, and Radix UI.

## Getting Started

1. **Install Dependencies:**
   ```sh
   npm install
   ```

2. **Run Development Server:**
   ```sh
   npm run dev
   ```
   The application runs locally on `http://localhost:5173`.

3. **Production Build:**
   ```sh
   npm run build
   ```
